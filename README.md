🚀 Uber Ride Analytics Dashboard

## 📊 Project Overview
This project presents an interactive Power BI dashboard analyzing Uber ride data to identify trends, cancellations, and customer behavior.

## 📁 Dataset
Dataset obtained from Kaggle.

## 🔍 Key Insights
- Booking trends over time
- Cancellation analysis
- Customer vs driver cancellations
- Revenue contribution
- Ride distance distribution

## 🛠 Tools Used
- Power BI
- Excel / CSV
- Data Visualization
